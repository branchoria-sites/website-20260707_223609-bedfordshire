## Introduction

In [Caithness]({{ 'where-caithness-folklore-meets-the-edge/' | relative_url }}) tradition, some brochs became fairy places because they looked like doorways into a hidden past: low, turf-covered stone mounds, once great Iron Age towers, standing in an open landscape where old ruins were easy to imagine as hollow hills. The clearest Caithness example is Bruan Broch in Latheron parish, remembered in a tale collected by the Reverend George Sutherland and published in 1937, in which two men hear fairy music at New Year, find the broch open, and discover that time inside the fairy dance does not match time outside it.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://britishfolklore.com/bruan-broch/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: britishfolklore.com">[britishfolklore.com]</a><span class="citation-popover" role="note"><span class="citation-popover-source">britishfolklore.com</span><span class="citation-popover-title">bruan broch</span><span class="citation-popover-snippet">British FolkloreDecember 1, 2023 — In Latheron parish there are the remains of a broch known as the fairy mound of Bruan...</span><span class="citation-popover-meta">Published: December 1, 2023</span></span></span>



<img src="{{ "/assets/images/Caithness_d273a3_fairy_brochs_c051f6-overview.webp" | relative_url }}" alt="Overview image for Fairy Brochs" loading="eager" decoding="sync" fetchpriority="high">

This is not evidence that Iron Age broch-builders themselves believed in fairies. It is later folklore attached to prehistoric remains. That distinction matters. Caithness has one of Scotland’s richest broch landscapes, with more brochs than anywhere else in the country, so its ruins offered later storytellers a ready-made geography of mystery: ancient, circular, half-buried, and often difficult to explain without archaeology.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.thebrochproject.co.uk/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: thebrochproject.co.uk">[Caithness Broch Project]</a><span class="citation-popover" role="note"><span class="citation-popover-source">thebrochproject.co.uk</span><span class="citation-popover-snippet">Caithness Broch ProjectCaithness Broch Project - Archaeology in Caithness, ScotlandCaithness, in the far north of Scotland, has more broc...</span></span></span>

## Why Brochs Invited Supernatural Stories

Brochs were massive round stone towers built in the Iron Age, found mainly in northern Scotland and the islands. Historic Environment Scotland describes them as distinctive double-walled towers, probably built between about 400 BC and AD 200, with inward-sloping walls, upper floors and sophisticated dry-stone engineering.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://blog.historicenvironment.scot/2018/01/building-the-broch/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: blog.historicenvironment.scot">[Historic Environment Scotland Blog]</a><span class="citation-popover" role="note"><span class="citation-popover-source">blog.historicenvironment.scot</span><span class="citation-popover-title">Historic Environment Scotland Blog Building A Broch</span><span class="citation-popover-snippet">Historic Environment Scotland Blog Building A Broch</span></span></span> In modern archaeological language they are complex roundhouses, likely serving several roles: high-status homes, places of defence, community centres or symbols of local power.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.highlifehighland.com/attractions/caithness-broch-centre/what-is-a-broch" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: highlifehighland.com">[High Life Highland]</a><span class="citation-popover" role="note"><span class="citation-popover-source">highlifehighland.com</span><span class="citation-popover-snippet">Open source on highlifehighland.com.</span></span></span>

To later rural communities, however, a ruined broch did not look like a neat museum diagram. Many surviving sites had collapsed into grassy or stony mounds. Bruan itself is officially described as a grass-covered stony mound with traces of walling, set on an artificial platform with surrounding ditch and outer bank, near the coast at about 80 metres above sea level.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://portal.historicenvironment.scot/apex/f?p=1505%3A300%3A%3A%3A%3A%3AVIEWTYPE%2CVIEWREF%3Adesignation%2CSM529" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: portal.historicenvironment.scot">[Historic Environment Scotland]</a><span class="citation-popover" role="note"><span class="citation-popover-source">portal.historicenvironment.scot</span><span class="citation-popover-title">Historic Environment Scotland Bruan, broch 85m SW of Tulloch Lea (SM529</span><span class="citation-popover-snippet">Historic Environment Scotland Bruan, broch 85m SW of Tulloch Lea (SM529</span></span></span> That physical form helps explain the fairy association. A broch could seem less like a ruined house than a sealed, inhabited hill.

Caithness made this process especially likely because brochs are so common there. The Caithness Broch Project says the county has more brochs than anywhere else in Scotland, while the Caithness Broch Centre describes Caithness as having the highest density of brochs in the country.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.thebrochproject.co.uk/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: thebrochproject.co.uk">[Caithness Broch Project]</a><span class="citation-popover" role="note"><span class="citation-popover-source">thebrochproject.co.uk</span><span class="citation-popover-snippet">Caithness Broch ProjectCaithness Broch Project - Archaeology in Caithness, ScotlandCaithness, in the far north of Scotland, has more broc...</span></span></span> For local tradition, that density matters. A single impressive ruin might become a landmark; a whole landscape of ruins becomes a pattern. Once people had stories about one mound, neighbouring brochs, cairns and old earthworks could be folded into the same imaginative map.

The fairy explanation also fitted a broader Scottish habit of treating ancient mounds, cairns and underground spaces as dwellings of hidden beings. Historic Environment Scotland’s recent guide to Gaelic fairy lore stresses that Scottish fairies were not merely charming decorative figures but dangerous, morally unpredictable beings associated with abduction, substitution and strange encounters.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://blog.historicenvironment.scot/2025/06/scary-fairies-scotlands-gaelic-fairy-folklore/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: blog.historicenvironment.scot">[Historic Environment Scotland Blog]</a><span class="citation-popover" role="note"><span class="citation-popover-source">blog.historicenvironment.scot</span><span class="citation-popover-snippet">Open source on historicenvironment.scot.</span></span></span> In Caithness, brochs did not need to be invented as fantasy castles. Their real archaeology already supplied the essential ingredients: age, stone, darkness, circular walls and a suggestion of a chambered interior.

## Bruan Broch and the Fairy Music Tale

Bruan Broch is the key Caithness case because it preserves the whole mechanism of the tradition in one memorable story. The site lies near Bruan, in the parish of Latheron, close to the east coast south of Wick. Historic Environment Scotland identifies it as a scheduled monument: a broch dating to the Iron Age, visible today as a grass-covered stony mound with surviving traces of walling and surrounding earthworks.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://portal.historicenvironment.scot/apex/f?p=1505%3A300%3A%3A%3A%3A%3AVIEWTYPE%2CVIEWREF%3Adesignation%2CSM529" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: portal.historicenvironment.scot">[Historic Environment Scotland]</a><span class="citation-popover" role="note"><span class="citation-popover-source">portal.historicenvironment.scot</span><span class="citation-popover-title">Historic Environment Scotland Bruan, broch 85m SW of Tulloch Lea (SM529</span><span class="citation-popover-snippet">Historic Environment Scotland Bruan, broch 85m SW of Tulloch Lea (SM529</span></span></span>

The folklore version was recorded from the Reverend George Sutherland’s *Folklore Gleanings and Character Sketches from the Far North*, published by the *John o’ Groat Journal* in Wick in 1937. Later folklore sites and retellings identify the ruin as “the fairy mound of Bruan” and summarise Sutherland’s tale: two men are carrying a small keg of whisky for New Year celebrations when they hear music near the broch. The broch is open. Inside, fairies are dancing to bagpipe music. One man goes in to join them; the other waits outside.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://britishfolklore.com/bruan-broch/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: britishfolklore.com">[britishfolklore.com]</a><span class="citation-popover" role="note"><span class="citation-popover-source">britishfolklore.com</span><span class="citation-popover-title">bruan broch</span><span class="citation-popover-snippet">British FolkloreDecember 1, 2023 — In Latheron parish there are the remains of a broch known as the fairy mound of Bruan...</span><span class="citation-popover-meta">Published: December 1, 2023</span></span></span>

The power of the story lies in its timing. The waiting man calls to his friend, who says he has not yet had a dance. After a long wait, the cautious man leaves, expecting his companion to come home by morning. But the next day the man is still missing, and the broch has closed again, with no visible door and no sign of disturbance.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://britishfolklore.com/bruan-broch/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: britishfolklore.com">[britishfolklore.com]</a><span class="citation-popover" role="note"><span class="citation-popover-source">britishfolklore.com</span><span class="citation-popover-title">bruan broch</span><span class="citation-popover-snippet">British FolkloreDecember 1, 2023 — In Latheron parish there are the remains of a broch known as the fairy mound of Bruan...</span><span class="citation-popover-meta">Published: December 1, 2023</span></span></span>

The rescue depends on an old rule of fairy tradition. The man returns on the anniversary, when the same scene is expected to repeat. The broch is open again; the music and dancing continue; his friend still thinks almost no time has passed. The rescuer places an iron object in the doorway to stop the fairies closing it, then drags his friend out by force. Only when the returned man sees that his own child does not recognise him does he accept that he has been away for a year.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://britishfolklore.com/bruan-broch/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: britishfolklore.com">[britishfolklore.com]</a><span class="citation-popover" role="note"><span class="citation-popover-source">britishfolklore.com</span><span class="citation-popover-title">bruan broch</span><span class="citation-popover-snippet">British FolkloreDecember 1, 2023 — In Latheron parish there are the remains of a broch known as the fairy mound of Bruan...</span><span class="citation-popover-meta">Published: December 1, 2023</span></span></span>

This tale is striking because it joins several well-known fairy motifs to one specific Caithness ruin:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* **Music from inside the mound:** the hidden world announces itself through sound before it is seen.
* **The open door:** the mound is not just a heap of stone but a threshold that appears and vanishes.
* **Lost time:** what feels like an hour inside the fairy dance becomes a year outside.
* **Iron as protection:** the rescuer uses iron to keep the doorway open, a common protective idea in British and Scottish fairy lore.
* **New Year timing:** the story happens around a liminal festival moment, when ordinary social order is already briefly suspended.

</div>

The result is not simply “fairies lived in a broch”. It is a story about crossing a boundary. The broch becomes a machine for changing time, memory and belonging. The man who enters is not killed, but he is removed from ordinary life long enough for his home to become strange to him.

## When Did Caithness Brochs Become Fairy Places?

The safest answer is that the fairy associations are later than the brochs themselves and are best documented in modern printed folklore from the nineteenth and twentieth centuries, not in Iron Age evidence. Bruan Broch was built or occupied in the broad Iron Age period; Historic Environment Scotland dates the monument type between 600 BC and AD 400 in its Bruan scheduling record.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://portal.historicenvironment.scot/apex/f?p=1505%3A300%3A%3A%3A%3A%3AVIEWTYPE%2CVIEWREF%3Adesignation%2CSM529" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: portal.historicenvironment.scot">[Historic Environment Scotland]</a><span class="citation-popover" role="note"><span class="citation-popover-source">portal.historicenvironment.scot</span><span class="citation-popover-title">Historic Environment Scotland Bruan, broch 85m SW of Tulloch Lea (SM529</span><span class="citation-popover-snippet">Historic Environment Scotland Bruan, broch 85m SW of Tulloch Lea (SM529</span></span></span> Sutherland’s published version of the fairy story, by contrast, belongs to 1937, although it clearly presents itself as an older local belief rather than a new literary invention.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.thenorthernantiquarian.org/2010/08/10/bruan-broch/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: thenorthernantiquarian.org">[thenorthernantiquarian.org]</a><span class="citation-popover" role="note"><span class="citation-popover-source">thenorthernantiquarian.org</span><span class="citation-popover-snippet">Bruan Broch, Caithness, Scotland10 Aug 2010 — Such was the case here, in the story described at this ruinous old site by George Sutherlan...</span></span></span>

That gap is important. Folklore can preserve old patterns of thought, but it should not be treated as a direct memory of broch-building society. The people who told the Bruan story were looking at a ruin already ancient beyond local memory. They knew it was old; they did not necessarily know what it had been for. Fairy lore supplied a way to make such places meaningful, dangerous and narratively alive.

There is also a wider pattern in Caithness antiquities. Later folklore sources note several prehistoric places in the county with fairy names or associations. A horned cairn near Lower Dounreay, for example, is recorded as “The Fairies’ Mound” or Cnoc na H-Uiseig in Highland Historic Environment Record material, and it was excavated in 1928 by A. J. H. Edwards.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://her.highland.gov.uk/Monument/MHG2479" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: her.highland.gov.uk">[Highland Historic Environment Record]</a><span class="citation-popover" role="note"><span class="citation-popover-source">her.highland.gov.uk</span><span class="citation-popover-snippet">Open source on highland.gov.uk.</span></span></span> Leslie Grinsell’s survey of folklore at prehistoric sites also lists Caithness examples including a fairies’ mound near Reay, fairy hillocks, a broch near Spittal associated with a fairy hillock, and other sites with fairy-related names.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.academia.edu/58443207/Grinsell_Folklore_of_Prehistoric_Sites_in_Scotland_and_Man" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: academia.edu">[Academia]</a><span class="citation-popover" role="note"><span class="citation-popover-source">academia.edu</span><span class="citation-popover-title">Grinsell Folklore of Prehistoric Sites in Scotland and Man</span><span class="citation-popover-snippet">Grinsell Folklore of Prehistoric Sites in Scotland and Man</span></span></span>

This does not mean every Caithness broch had a fairy story. The evidence is uneven. Bruan is unusually vivid because the tale was written down in a form that names the place, gives a plot and preserves the key rules of the encounter. Other sites may have had names, warnings or local anecdotes that were never collected, or that survive only in place-name memory.

## The Broch as a Fairy Mound, Not Just a Ruin

The phrase “fairy mound” changes how a reader should imagine the site. It is not simply a ruin with fairies added as decoration. In the Bruan tale, the broch’s archaeology and the folklore are working together. The real monument is circular, ancient and partly buried; the imagined monument is hollow, openable and inhabited. One is visible by daylight; the other appears at a special moment.

This is a common transformation in folk tradition. A prehistoric structure that has lost its obvious everyday purpose becomes a place where another kind of society might live. The fairies at Bruan dance, play music and mark time differently from humans. They are not ghosts of the Iron Age inhabitants in any simple sense. They are a later supernatural people occupying an older human place.

The story also shows why brochs were especially suitable for fairy lore compared with ordinary ruins. A ruined cottage is familiar: people know what it was and how it worked. A broch is harder to read. Its thick circular walls, internal passages and collapsed core suggest hidden rooms even when none are accessible. Historic Environment Scotland’s general broch description emphasises features such as double walls and stairs within the wall thickness, details that can make a broch seem architecturally secretive even to modern visitors.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://blog.historicenvironment.scot/2018/01/building-the-broch/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: blog.historicenvironment.scot">[Historic Environment Scotland Blog]</a><span class="citation-popover" role="note"><span class="citation-popover-source">blog.historicenvironment.scot</span><span class="citation-popover-title">Historic Environment Scotland Blog Building A Broch</span><span class="citation-popover-snippet">Historic Environment Scotland Blog Building A Broch</span></span></span>

Bruan’s present form reinforces that feeling. As a grass-covered stony mound with traces of walling and outer works, it sits between categories: not fully a tower, not merely a hill, not easily legible from a distance.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://portal.historicenvironment.scot/apex/f?p=1505%3A300%3A%3A%3A%3A%3AVIEWTYPE%2CVIEWREF%3Adesignation%2CSM529" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: portal.historicenvironment.scot">[Historic Environment Scotland]</a><span class="citation-popover" role="note"><span class="citation-popover-source">portal.historicenvironment.scot</span><span class="citation-popover-title">Historic Environment Scotland Bruan, broch 85m SW of Tulloch Lea (SM529</span><span class="citation-popover-snippet">Historic Environment Scotland Bruan, broch 85m SW of Tulloch Lea (SM529</span></span></span> Folklore often thrives in exactly that middle state, where a real feature is visible but its explanation is incomplete.

## What the Bruan Story Says About Caithness Identity

Bruan Broch matters because it joins two of Caithness’s strongest cultural signatures: prehistoric stone architecture and northern fairy tradition. Caithness is now often promoted through its broch landscape, with local heritage groups using brochs to tell a distinctive story about Iron Age life, craft and settlement in the far north.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.thebrochproject.co.uk/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: thebrochproject.co.uk">[Caithness Broch Project]</a><span class="citation-popover" role="note"><span class="citation-popover-source">thebrochproject.co.uk</span><span class="citation-popover-snippet">Caithness Broch ProjectCaithness Broch Project - Archaeology in Caithness, ScotlandCaithness, in the far north of Scotland, has more broc...</span></span></span> The fairy tale adds another layer: it shows how those same ruins lived in popular imagination before and alongside modern archaeology.

The setting is also very Caithness. The men are not wandering through a vague enchanted forest. They are moving through a recognisable rural landscape at New Year, carrying whisky, passing near Bruan church, and encountering the supernatural close to a known monument.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.thenorthernantiquarian.org/2010/08/10/bruan-broch/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: thenorthernantiquarian.org">[thenorthernantiquarian.org]</a><span class="citation-popover" role="note"><span class="citation-popover-source">thenorthernantiquarian.org</span><span class="citation-popover-snippet">Bruan Broch, Caithness, Scotland10 Aug 2010 — Such was the case here, in the story described at this ruinous old site by George Sutherlan...</span></span></span> The story belongs to a county of roads, farms, coastal settlements and old stone sites, not to an abstract Celtic dreamscape.

The New Year detail is especially apt. Hogmanay and the turning of the year are moments when thresholds matter: old and new, outside and inside, safety and risk. In the Bruan tale, that seasonal threshold is mirrored by the open door in the mound. The man who enters the dance crosses both at once. He steps into the fairy interior at the very time when the ordinary year is changing outside.

This makes the tale more than a spooky anecdote. It is a local way of thinking about disappearance, loyalty and return. The cautious friend does not simply witness the marvel; he remembers the rule, comes back after a year, and rescues the man who has been caught in fairy time. Caithness folklore here is not only about danger. It is also about social bonds strong enough to reach into the hidden world.

## Modern Heritage Retellings and Public Imagination

Today, Bruan’s fairy story circulates through folklore websites, local heritage writing and public-facing broch interpretation rather than only through oral telling. British Folklore, Folklore Scotland, The Modern Antiquarian and The Northern Antiquarian all retell or preserve versions of the Bruan story, usually crediting Sutherland’s 1937 collection.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://folklorescotland.com/the-fairies-of-bruan-broch/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: folklorescotland.com">[folklorescotland.com]</a><span class="citation-popover" role="note"><span class="citation-popover-source">folklorescotland.com</span><span class="citation-popover-snippet">Open source on folklorescotland.com.</span></span></span>

The Caithness Broch Project has also helped bring brochs into modern public imagination. Its work is archaeological and educational rather than primarily supernatural, but it openly recognises the storytelling power of brochs. In a blog post on brochs and stories, the project notes that brochs were associated by later people with fairy abductions and specifically names Bruan Broch near Clyth as the site of such a tale.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.thebrochproject.co.uk/blog/on-brochs-and-stories" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: thebrochproject.co.uk">[Caithness Broch Project]</a><span class="citation-popover" role="note"><span class="citation-popover-source">thebrochproject.co.uk</span><span class="citation-popover-title">on brochs and stories</span><span class="citation-popover-snippet">on brochs and stories</span></span></span>

That modern retelling creates a useful balance. Archaeology explains what brochs were as Iron Age buildings; folklore explains how later communities emotionally inhabited their ruins. The two should not be collapsed into each other. A broch is not “really” a fairy mound in archaeological terms, and the fairy tale is not a factual report of the Iron Age. But the folklore is still historically valuable because it records how Caithness people made sense of ancient places long after their original use had been forgotten.

The current heritage revival makes that layered meaning more visible. Caithness Broch Project describes itself as a grassroots charity aiming to conserve and celebrate the archaeology of Caithness, and local visitor material now presents the county as a place where brochs are central to identity.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.thebrochproject.co.uk/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: thebrochproject.co.uk">[Caithness Broch Project]</a><span class="citation-popover" role="note"><span class="citation-popover-source">thebrochproject.co.uk</span><span class="citation-popover-snippet">Caithness Broch ProjectCaithness Broch Project - Archaeology in Caithness, ScotlandCaithness, in the far north of Scotland, has more broc...</span></span></span> In that context, the Bruan fairy tale is not a distraction from “real history”. It is part of the afterlife of the broch landscape.

## How to Read the Tradition Today

The best way to read Caithness fairy broch stories is neither as literal supernatural evidence nor as meaningless fantasy. They are place-based traditions that reveal how communities responded to ancient architecture in the landscape. Bruan Broch was already a real, nationally important Iron Age site; the fairy tale made it socially memorable in another register.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://portal.historicenvironment.scot/apex/f?p=1505%3A300%3A%3A%3A%3A%3AVIEWTYPE%2CVIEWREF%3Adesignation%2CSM529" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: portal.historicenvironment.scot">[Historic Environment Scotland]</a><span class="citation-popover" role="note"><span class="citation-popover-source">portal.historicenvironment.scot</span><span class="citation-popover-title">Historic Environment Scotland Bruan, broch 85m SW of Tulloch Lea (SM529</span><span class="citation-popover-snippet">Historic Environment Scotland Bruan, broch 85m SW of Tulloch Lea (SM529</span></span></span>

For a visitor or reader, three cautions help keep the story grounded:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* **Do not back-date the fairies to the Iron Age.** The broch is ancient, but the attested fairy story is much later.
* **Do not treat all brochs as fairy brochs.** Bruan is the named Caithness case with a strong collected tale; other sites vary in evidence.
* **Do not dismiss the folklore because it is not archaeology.** Local legend is evidence for later belief, memory and imagination, even when it is not evidence for prehistoric use.

</div>

Bruan Broch’s value lies in precisely this overlap. It is an Iron Age monument, a grassed-over ruin, a scheduled archaeological site, a remembered fairy mound and a modern heritage story. Its fairy music tale shows how Caithness tradition could turn stone remains into active thresholds: places where the past did not simply sit in the ground, but opened, played music, and briefly took people out of ordinary time.

    if (persist) {
      try { if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId); } catch (err) {}
    }
    closeMenu(section);
  }
  sections.forEach(function (section) {
    if (section.getAttribute('data-ebay-localized-init') === '1') return;
    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
